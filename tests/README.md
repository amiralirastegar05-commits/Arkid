# Additional integration tests

`npm test` runs the standard Node/PGlite suite. The scripts below are optional: they require tools that are not production dependencies and **do not contact Supabase or use real account data**.

## Responsive browser smoke test

Serve locally from a temporary Node server, intercept Supabase's browser SDK with an in-memory mock, and exercise the social/profile pages at 320, 375, 768, 1024, and 1440 CSS pixels. It checks horizontal overflow, minimum social action target size, opt-in privacy, and two-column desktop layout. It does not replace manual tests on real devices and other browser engines.

The mock also exercises reporting, moderator access and block/unblock controls. Install `playwright-core` separately without saving it as a dependency and provide an installed browser via `CHROMIUM_PATH`, then run `npm run test:responsive` and `npm run test:ranked-browser`. The second test plays a completed ranked game at 320 and 1440px, reloads/resumes, and submits to a fake API. Alternatively install `@sparticuz/chromium` without saving it; if `CHROMIUM_PATH` is unset the script uses its executable and launch arguments. Some Linux environments also require OS libraries. The regular `npm ci` installs only the standard suite's dependencies.

## Local PostgreSQL concurrency test

`tests/postgres/concurrency.mjs` deliberately refuses to run unless `ARKID_DISPOSABLE_PG=yes`, the server is reached through the fixed Unix socket `/tmp/arkid-pg-socket` port `55439`, `show data_directory` returns `/tmp/arkid-pg-test`, and `listen_addresses` is empty. It creates roles and a newly named test database with synthetic records in that **disposable local cluster**. Never point it at a real, shared or production cluster. No automatic data deletion is performed. The optional `pg` Node package must be made available, for example through `NODE_PATH`.

Prepare and start a PostgreSQL 17 test cluster at those exact paths with TCP listening disabled, then run `ARKID_DISPOSABLE_PG=yes npm run test:postgres-local`. The test holds the first transaction open and checks a second connection actually waits before testing simultaneous team creation, competing joins, capacity, invite limits, blocks racing with invitation creation and acceptance, concurrent ranked start/commit, and concurrent report resolution. Run `ARKID_DISPOSABLE_PG=yes npm run test:ranked-postgres` on the same cluster for a complete Worker-to-PostgreSQL ranked round with fake Auth/REST transport. With both optional browser and pg packages available, `ARKID_DISPOSABLE_PG=yes npm run test:social-postgres-browser` runs two synthetic browser accounts end-to-end against real local PostgreSQL using a fake Auth/PostgREST adapter, including invitation, block, report and reviewer flows. `ARKID_DISPOSABLE_PG=yes npm run test:ranked-postgres-browser` additionally plays through the mobile browser UI and Worker to the local PostgreSQL ledger, with fake Auth/REST. These cover selected races, not every concurrency or distributed abuse scenario, and they do not prove the hosted project's configuration or real hosted Auth/REST.
